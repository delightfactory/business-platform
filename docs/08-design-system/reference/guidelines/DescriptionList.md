# DescriptionList

عرض حقائق السجل في أزواج تسمية وقيمة، وخط زمني لتاريخه.

- `bp-dl` داخل بطاقة بعنوان، وإجراء «تعديل» واحد في رأس البطاقة يفتح درجًا أو نموذجًا لهذه المجموعة فقط.
- القيمة الفارغة تُكتب «غير محدد» بلون `text-subtle`، ولا يُحذف الصف.
- القيم الحساسة (الأجر، الحساب البنكي) تُخفى افتراضيًا وتُكشف بطلب صريح.
- `bp-timeline` يعرض ما تغيّر ومتى ومن غيّره، والأحدث أولًا. الحالة السارية معلّمة بـ `is-current`.
- المدد تُكتب بوحدات مقروءة: «8 ساعات» لا «480 دقيقة».

يقدّم المستهلك: الأزواج، أو أحداث الخط الزمني.
