# Button

زر الإجراء. استخدم **أساسيًا واحدًا** فقط في كل منطقة (رأس الصفحة، تذييل النافذة، شريط النموذج)، وكل ما عداه ثانوي أو شبحي.

- `bp-btn--primary`: المهمة التي جاءت الصفحة من أجلها. `bp-btn--secondary`: إجراءات مساندة. `bp-btn--ghost`: الإلغاء وإجراءات الصف وشريط الأدوات.
- `bp-btn--danger` يظهر فقط داخل نافذة التأكيد. خارجها استخدم `bp-btn--danger-ghost` أو عنصر قائمة هدّام، حتى لا ينافس الزر الأساسي.
- النص فعل يصف النتيجة: «إضافة موظف»، «اعتماد اليوم». لا «موافق» ولا «تنفيذ».
- الأيقونة قبل النص، وزر الأيقونة وحده يحمل `aria-label` دائمًا.
- أثناء الإرسال: `aria-busy="true"` مع `bp-spinner` ونص المضارع («جارٍ الحفظ…») ويُمنع الضغط المكرر.
- الارتفاع `control-md` على سطح المكتب، `control-lg` على الهاتف، `control-sm` داخل الجداول وأشرطة الأدوات.
- الزر يأخذ عرض محتواه. `bp-btn--block` لشاشات الدخول وشريط الإجراء السفلي على الهاتف فقط.

يقدّم المستهلك: النص، النوع، الأيقونة الاختيارية، وحالة الانتظار.
