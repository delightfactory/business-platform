# Badge

شارة الحالة: نقطة ملونة وكلمة. اللون لا يحمل المعنى وحده أبدًا.

قاموس الحالات موحّد في كل المجالات:

| الدلالة | الصنف | أمثلة |
| --- | --- | --- |
| مكتمل أو ساري | `bp-badge--success` | نشط، معتمد، مقبولة، أُرسلت |
| مجدول أو قيد التنفيذ | `bp-badge--info` | يبدأ قريبًا، قيد المتابعة، بانتظار القبول |
| يحتاج قرارًا من المستخدم | `bp-badge--warning` | يحتاج مراجعة، لم يتأكد الإرسال، قريب من الحد |
| فشل أو مرفوض | `bp-badge--danger` | تعذر الإرسال، مرفوض |
| منتهٍ أو غير فعّال | بلا صنف (محايد) | انتهت خدمته، ملغاة، غير نشط |
| جاهز للخطوة التالية | `bp-badge--brand` | جاهز للاعتماد |

- كلمة أو كلمتان بصيغة ثابتة لكل حالة في كل الشاشات.
- شارة واحدة للحالة في كل صف. التفاصيل تذهب إلى عمود أو تلميح.
- `bp-badge--count` للعدادات في التبويبات والتنقل، و`bp-tag` للفلاتر المفعّلة والتصنيفات.

يقدّم المستهلك: مفتاح الحالة؛ والمكون يحدد اللون والنص من القاموس.
