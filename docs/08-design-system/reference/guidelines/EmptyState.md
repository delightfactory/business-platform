# EmptyState

الحالات غير المحمّلة: فارغ لأول مرة، لا نتائج، تعذر التحميل، وهيكل التحميل.

كل قائمة وكل صفحة تعرّف حالاتها الخمس قبل اعتمادها:

1. **تحميل**: `bp-skel` بشكل المحتوى القادم. لا صفحة بيضاء ولا مؤشر دوّار يملأ الشاشة.
2. **فارغ لأول مرة**: ما هذا المكان، ولماذا هو فارغ، والإجراء الذي يملؤه.
3. **لا نتائج**: يسمّي البحث الحالي ويعرض «مسح البحث والفلاتر».
4. **تعذر التحميل**: يقول إن شيئًا لم يتغير ويعرض «إعادة المحاولة».
5. **غير متاح**: بلا صلاحية أو الوحدة غير مفعّلة، مع الجهة التي تملك التفعيل.

- الأيقونة من نفس أيقونة القسم في التنقل. لا رسوم توضيحية.
- المستخدم الذي لا يملك صلاحية الإضافة يرى النص دون الزر.

يقدّم المستهلك: نوع الحالة، العنوان، النص، والإجراءات.
