# Dialog

نافذة تأكيد لقرار له أثر، أو لمهمة قصيرة لا تحتاج صفحة.

- العنوان سؤال يسمّي الفعل والسجل: «خفض دور أحمد سامي إلى عضو؟». لا «هل أنت متأكد؟».
- الجسم `bp-impact` يعدّد الأثر الفعلي: ما يتغير الآن، ما يبقى، وهل يمكن التراجع.
- زر التأكيد يكرر فعل العنوان («خفض الدور») ويأخذ `bp-btn--danger` إن كان الفعل هدّامًا. «إلغاء» ثانوي قبله.
- الفعل القابل للعكس فورًا لا يحتاج نافذة: نفّذه وأظهر `Toast` مع «تراجع».
- الفعل غير القابل للعكس على بيانات مالية أو جماعية يطلب كتابة اسم السجل للتأكيد.
- النافذة تحبس التركيز، تُغلق بـ Esc، وتعيد التركيز إلى الزر الذي فتحها. العرض 480px، وعلى الهاتف ورقة سفلية.
- لا تُستخدم عناصر الإفصاح داخل الصف لتأكيد الإجراءات.

يقدّم المستهلك: العنوان، قائمة الأثر، ونص زر التأكيد ونوعه.
