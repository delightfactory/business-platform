# ScreenRecord

صفحة سجل: ملف الموظف. النموذج المرجعي لكل صفحة تفاصيل.

- رأس هوية ثابت: الصورة الرمزية، الاسم، الحالة، وسطر الحقائق. الإجراءات النادرة والهدّامة (نقل، إنهاء الخدمة) في قائمة «…».
- تبويبات بدل تكديس كل الألواح في عمود واحد طويل: نظرة عامة، العمل والدوام، الأجر، الحضور، حساب الدخول، السجل. كل تبويب برابطه.
- «نظرة عامة» عمودان: الحقائق في العمود الأعرض، والحالة والتاريخ في الأضيق.
- كل بطاقة تُعدَّل وحدها عبر `Drawer`. لا نماذج مفتوحة دائمًا داخل الصفحة.
- المبلغ مخفي افتراضيًا ويظهر فقط لمن يملك صلاحية الاطلاع على الأجور.
- العدّاد على تبويب «الحضور» يدل على ما ينتظر مراجعة لهذا الموظف.
