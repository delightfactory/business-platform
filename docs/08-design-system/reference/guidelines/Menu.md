# Menu

قائمة منسدلة لإجراءات الصف، وقائمة الحساب، ومبدّل الشركة.

- إجراءات السجل الثانوية كلها في قائمة واحدة خلف زر «…». لا صف من الأزرار المتشابهة داخل كل سجل.
- الترتيب: الأكثر استخدامًا أولًا، والهدّام آخرًا بعد فاصل وبصنف `bp-menu__item--danger`.
- الإجراء الذي يفتح نافذة تأكيد ينتهي بثلاث نقاط «…».
- لا يظهر عنصر لا يملك المستخدم صلاحيته. العنصر المعطّل مؤقتًا يبقى ظاهرًا مع سبب تعطيله.
- مبدّل الشركة جزء من قائمة مساحة العمل أعلى الشريط الجانبي: الشركة الحالية معلّمة، والتبديل يعيد إلى الصفحة الرئيسية للشركة الجديدة.
- لوحة المفاتيح: الأسهم للتنقل، Enter للتنفيذ، Esc للإغلاق مع عودة التركيز إلى الزر.

يقدّم المستهلك: العناصر المسموحة للمستخدم الحالي.
