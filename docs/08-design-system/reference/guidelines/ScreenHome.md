# ScreenHome

الصفحة الرئيسية لمساحة الشركة: ما يحتاج قرارًا اليوم، ثم حالة الاستخدام، ثم إعداد لم يكتمل.

- القسم الأول «يحتاج إجراءً منك»: قائمة يغذّيها كل مجال بما ينتظر هذا المستخدم تحديدًا حسب صلاحياته. كل عنصر يسمّي العدد والمجال ويفتح الإجراء مباشرة. عند فراغها تقول «لا شيء ينتظرك الآن».
- المؤشرات أربعة حقيقية: اثنان من مجال العمل، واثنان لاستهلاك الاشتراك (المقاعد، الفروع) بشريط نحو الحد.
- «إعداد الشركة» قائمة تحقق تظهر للمسؤول حتى تكتمل ثم تختفي.
- لا روابط تكرر التنقل الجانبي، ولا بطاقات لمجالات غير مفعّلة.
- العضو بلا صلاحيات إدارية يرى القسم الأول فقط بما يخصه.
