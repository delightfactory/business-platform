# Field

حقل إدخال بتسمية ثابتة فوقه، وتلميح أو خطأ تحته. التسمية ليست نصًا بديلًا داخل الحقل أبدًا.

- الترتيب دائمًا: `bp-label` ثم الحقل ثم `bp-hint` أو `bp-error`. الخطأ يحل محل التلميح ويرتبط بـ `aria-describedby`.
- الحقول المطلوبة هي الأصل ولا تُعلَّم. علّم الاختياري فقط بـ `bp-opt` «(اختياري)».
- الخطأ يقول ما حدث وكيف يُصلح، عند الحقل نفسه. خطأ عام واحد أسفل النموذج غير مقبول.
- التحقق عند مغادرة الحقل وعند الإرسال، لا أثناء الكتابة. عند فشل الإرسال ينتقل التركيز إلى أول حقل خاطئ.
- القوائم التي تتجاوز 7 خيارات (الفروع، الوظائف، الموظفون) تستخدم حقل بحث واختيار، لا `select` أصليًا.
- المبالغ: أرقام لاتينية جدولية، والعملة لاحقة `bp-affix`. التاريخ يُعرض مقروءًا «1 ديسمبر 2026» ولا يُعرض بصيغة ISO.
- الحد `border-control` يحقق 3:1. الحقل المعطّل يشرح سبب تعطيله في التلميح.
- على الهاتف: الارتفاع `control-lg` والخط 16px.

يقدّم المستهلك: المعرّف، التسمية، القيمة، التلميح، ورسالة الخطأ إن وجدت.
