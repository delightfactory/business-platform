# DataTable

جدول السجلات: المكوّن الأساسي لكل قائمة تتجاوز بضعة عناصر. بحث، فلاتر، فرز، تحديد جماعي، وترقيم صفحات.

- القائمة جدول على سطح المكتب: عمود لكل حقيقة يُفرز أو يُقارن بها. البطاقات المكدسة للهاتف فقط.
- العمود الأول هوية السجل (`bp-cell-main`: صورة رمزية، اسم، رمز) وهو رابط فتح السجل. الضغط على الصف يفتحه؛ لا زر «عرض» في كل صف.
- إجراءات الصف خلف زر «…» في عمود النهاية. إجراء واحد شائع جدًا يجوز إظهاره زرًا شبحيًا بجواره.
- شريط الأدوات: البحث فوري بلا زر (تأخير 300ms)، ثم الفلاتر `bp-filter`. الفلتر المفعّل يتحول إلى `bp-filter--on` ويُزال بضغطة. البحث والفلاتر والفرز والصفحة تُحفظ في الرابط.
- التذييل يعرض دائمًا «عرض 1 إلى 25 من 128» مع ترقيم الصفحات. لا «الصفحة 1» بلا إجمالي.
- التحديد يُظهر `bp-bulkbar` عائمًا بعدد المحدد والإجراءات الجماعية المسموحة.
- الأعمدة النصية بمحاذاة البداية، والمبالغ والأعداد بمحاذاة النهاية `bp-col-end` بأرقام جدولية.
- الكثافة: `row-default` (52px) افتراضيًا، و`bp-table--compact` (40px) لشاشات المراجعة والمحاسبة. الاختيار يُحفظ للمستخدم.
- على الهاتف يصير كل صف عنصر `bp-list__row`: الهوية، سطر ثانوي، والشارة. التمرير الأفقي ليس حلًا.

يقدّم المستهلك: تعريف الأعمدة، الصفوف، الإجمالي، حالة الفرز والفلاتر، والإجراءات حسب الصلاحية.
