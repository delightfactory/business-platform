# ScreenMobile

الهاتف: نفس المهمة بتركيب مختلف. مراجعة الحضور مثالًا، من القائمة إلى القرار.

- شريط تطبيق علوي `bp-appbar` بشعار الشركة وعنوان واحد. العنوان لا يتكرر داخل الصفحة.
- تنقل سفلي `bp-bottomnav` بأيقونة ونص: الرئيسية، أهم وجهتين للمستخدم، و«المزيد» الذي يفتح كل التنقل.
- القائمة `bp-list`: الصف كله يفتح السجل. سطر ثانٍ يحمل سبب الانتباه، والشارة في النهاية.
- الفلاتر رقائق قابلة للتمرير أفقيًا مع العدد، والأهم أولًا («يحتاج مراجعة»).
- صفحة القرار: الحقائق، ثم سبب الانتباه، ثم شريط إجراء سفلي ثابت بزر أساسي عريض `control-lg`.
- الحقول 16px لمنع تكبير المتصفح، وأهداف اللمس 44px فأعلى.
