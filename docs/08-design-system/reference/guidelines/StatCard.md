# StatCard

بطاقة مؤشر: تسمية، رقم، وسياق أو رابط للإجراء.

- تظهر فقط عندما يكون الرقم نفسه سبب زيارة الصفحة أو يقود إلى إجراء. لا صف مؤشرات زخرفي أعلى كل صفحة.
- الرقم `text-metric` بأرقام لاتينية جدولية، والمقام («من 20») بحجم النص وبلون `text-subtle`.
- كل بطاقة تنتهي بسياق: مقارنة، شريط `bp-meter` نحو حد، أو رابط إلى القائمة التي تشرح الرقم.
- الاستهلاك نحو حد الاشتراك (مقاعد، فروع) يتحول إلى `bp-meter--warning` عند 85% فما فوق.
- أربع بطاقات على الأكثر في الصف، بارتفاع واحد.

يقدّم المستهلك: التسمية، القيمة، والسياق أو الرابط.
