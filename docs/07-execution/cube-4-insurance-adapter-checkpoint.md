# Cube 4 insurance adapter checkpoint

The private `payroll.calculate_insurance` adapter computes employee/employer contributions and the separately pack-designated tax-deductible employee contribution from reviewed calendar-month obligations. Each month carries an explicit insured wage and immutable-source reference. Salary-cycle dates, salary proration, payment date and gross wages are not used to invent these obligations or replace the insured wage.

The stored immutable pack now has a separate `insurance_rules` object with one supported category, explicit wage bounds, bounded nonduplicate insurance branches, employee/employer rates, deductible treatment and branch/month cent rounding. No rate/category data or legally verified pack is inserted. Out-of-bound wages are rejected, never automatically clamped. Rules are validated even when the explicit reviewed obligation array is empty; missing/null obligations do not become empty. Unknown deductible applicability does not become false.

Obligations are ordered unique first-of-calendar-month dates, within one year and wholly inside the pack interval. A change inside an obligation month is unsupported and requires a verified rule/attribution path. Full start/end-month eligibility and benefit/exemption applicability remain upstream source qualification responsibilities. The function is private SECURITY INVOKER with empty search_path and revoked API-role EXECUTE. It does not expose finalization or infer that an employment is insured.

The [NOSI2026 limits notice](https://www.nosi.gov.eg/ar/News/Pages/2025-11-30.aspx) and [Law148/2019 first edition](https://www.nosi.gov.eg/ar/Lists/NOSILibrary/2-12-2019%20%D9%83%D8%AA%D8%A7%D8%A8%20%D8%A7%D9%84%D9%82%D8%A7%D9%86%D9%88%D9%86%20%D8%A7%D9%84%D8%AC%D8%AF%D9%8A%D8%AF.pdf) were reopened as source context. The notice distinguishes actual insured wage and category-dependent uses of the minimum; it does not justify a universal gross clamp. Current branch rates/applicability, later amendments and official numerical results are not qualified by this implementation.
