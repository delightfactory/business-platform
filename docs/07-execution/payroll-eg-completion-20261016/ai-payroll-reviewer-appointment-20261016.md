# تكليف المراجع الآلي للرواتب

## تفويض المالك

طلب المالك مباشرة تعيين نموذج يؤدي دور مراجع الرواتب بالأدوات والصلاحيات اللازمة لإنهاء المراجعة. المراجع المكلّف هو **Claude Opus 5.5 Medium** عبر Claude Code الرسمي، الجلسة **eaeb93ce-f7ab-455a-a397-85f5cca6cc57**. هذا تعيين لمراجع آلي مستقل، وليس تسجيل اسم محاسب بشري أو ادعاء اعتماد حكومي.

## نطاق العمل والصلاحيات

- قراءة التشريعات والإرشادات الرسمية ومراجعة النطاق والفئات والتواريخ، وتحديد الافتراضات والاستثناءات صراحة.
- إنشاء حاسبة مستقلة باستخدام Decimal وحالات متوقعة تغطي السيناريوهات العشرة. تُثبت النتائج وبصماتها قبل الاطلاع على محرك المنصة، لمنع نسخ المتوقع من الفعلي.
- تنفيذ الحسابات وتنزيل المستندات الرسمية وحفظ التقارير داخل دليل مراجعة معزول خارج OneDrive. لا بيانات موظفين حقيقية أو مفاتيح إنتاج في حزمة التكليف.
- بعد تثبيت المقارنات المستقلة: قراءة التنفيذ والبوابات، حصر الاختلافات وشروط قبولها. ينفذ المنسق المقارنة مع PostgreSQL الفعلي داخل QA بصورة مستقلة.
- لا صلاحية ذاتية لمنح حسابات إنتاج أو تنفيذ صرف أو تقديم إقرار أو تغيير اشتراك أو رفع/دمج/نشر. هذه ليست أدوات لازمة للمراجعة الحسابية. لا تغيير لتاريخ النتائج أو وضع مالي مؤهل يدويًا.

## تعديل المالك اللاحق: المراجعة اختيارية

ألغى المالك صراحة اشتراط المقارنات الرسمية أو اعتماد محاسب أو نموذج لتفعيل الإعدادات أو استخدام الرواتب. هذا القرار يحل محل سياسة الأدلة الإلزامية السابقة. التكليف الآلي هنا فحص جودة داخلي فقط؛ لا بوابة بديلة أو إقرار إجباري على الشركات. تظل نتائج النموذج مشتقة بصورة مستقلة ولا توصف بأنها صادرة عن جهة حكومية، وتبقى صلاحيات الاستخدام وصحة الأرقام والتواريخ والتدقيق ومنع التكرار.
