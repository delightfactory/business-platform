# حصر واجهات الموارد البشرية وحالة الإغلاق

الحالة: **الإغلاق غير مكتمل**. الحصر المصدري يشمل 43 صفحة فعلية: الموظفون 7، الحضور 9، الإجازات 13، الرواتب 9، الخدمة الذاتية 5. كل مسار ديناميكي يُعد صفحة واحدة؛ هذا لا يعني قبول كل سجل وحالة وصلاحية بصريًا. المرجع المعتمد: [التصور ج والخطة المدمجة](ux-visual-concept-c-plan.md).

## الدفعة الحالية
- إعادة التوظيف: الفروع تتبع جهة العمل المختارة، والوظائف تتبع القسم أو تكون عامة؛ لا تغيير للتحقق على الخادم أو الأجر أو تاريخ البداية.
- بنود الراتب: تمييز القيمة بالجنيه من النسبة المئوية. المصدر الحالي يسمح بالنسبة من الأجر الأساسي فقط، ويحسب القيمة المدخلة بقسمتها على 100.
- الاستحقاق السنوي: توضيح أن سبب التسجيل مطلوب من 3 أحرف، وشرح سبب تعطيل التأكيد، وتبسيط مدة الخدمة وعدد أيام السنة. شرط التسجيل وحساباته محفوظان؛ العلامة البصرية لا تفرض تحققًا أصليًا يمنع المعاينة أو حفظ السياسة.
- 28 صفحة إضافية تشارك عميل الخادم وقراءة المستخدم داخل الطلب نفسه مع الإطار؛ لا تخزين بين الطلبات أو الحسابات. لم يُقَس تحسن زمن التنقل بعد.

## ما يفصل التنفيذ عن إعلان الجاهزية
1. المراجعة المحلية توقفت عند رفض اتصال خدمة الدخول بقاعدة الاختبار: `SQLSTATE 28P01 — password authentication failed`. لم تُتجاوز المصادقة أو يُعَد إنشاء البيانات. أُغلقت خدمتا الواجهة والوكيل المحلي الخاصتان بالمحاولة؛ بقيت قاعدة البيانات وخدمات الاختبار الموجودة محفوظة. لا رابط هاتف جديد من هذه الدفعة.
2. بعد استعادة الاتصال المشروع: مرور مجمع واحد بأدوار الموظف ومسؤول الموارد والرواتب على التنقل، الحضور، طلب الإجازة ومراجعته، الموظف وإعادة توظيفه، ومدخلات المسير ومراجعته والتقارير. مراجعة جميع تبويبات الرواتب مطلوبة بعد ملاحظة المالك، مع فحص عرض الهاتف واستجابة الانتقال. لا إعادة اختبارات الخلفية غير المتغيرة، ولا تعديل معاملات حقيقية.
3. المالك يتولى اختبار جهازه الفعلي للموقع والتثبيت والملاحظات البصرية قبل النشر. لا إعلان جاهزية إنتاج أو دمج أو نشر في هذه الدفعة.

الفحوص: lint لجميع ملفات TSX المعدلة وبناء مجمع شامل TypeScript ناجحان. مقارنة الصفحات الـ28 أكدت أن الفروق فيها مقصورة على استدعاءات العميل والمستخدم، دون تغيير حراس الصلاحيات أو RPCs. لا تغيير في actions.ts أو Supabase، ولا إعادة اختبارات قاعدة البيانات.

المراجعة الرسمية المصدرية: Claude Opus 5.5 / Medium. ملاحظاته المشروطة عن أساس النسبة ووحدتها وحقول النموذج حُسمت بقراءة قواعد الخيارات والتحقق والحساب ومكوّن Field؛ لا بديل للنموذج ولا تغيير لإعدادات المزود العامة. لا تُعد المراجعة المصدرية إثباتًا للقبول المرئي.
