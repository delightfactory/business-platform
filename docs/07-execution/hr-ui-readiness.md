# حصر واجهات الموارد البشرية وحالة الإغلاق

الحالة: **اتصال الاختبار أُصلح؛ القبول النهائي للموديول غير مكتمل**. الحصر المصدري يشمل 43 صفحة فعلية: الموظفون 7، الحضور 9، الإجازات 13، الرواتب 9، الخدمة الذاتية 5. كل مسار ديناميكي يُعد صفحة واحدة؛ هذا لا يعني قبول كل سجل وحالة وصلاحية بصريًا. المرجع المعتمد: [التصور ج والخطة المدمجة](ux-visual-concept-c-plan.md).

## الدفعة الحالية
- لغة الواجهة: حصر النصوص الثابتة وتبسيط 408 مواضع في 84 ملفًا لمصطلحات العمل المصرية؛ [القاموس وحدود الحصر](egyptian-user-copy.md). الفروق نصية فقط، دون تغيير قواعد الحساب أو الصلاحيات أو المعاملات؛ لا تغلق بوابات القبول المالي أدناه.
- إعادة التوظيف: الفروع تتبع جهة العمل المختارة، والوظائف تتبع القسم أو تكون عامة؛ لا تغيير للتحقق على الخادم أو الأجر أو تاريخ البداية.
- بنود الراتب: تمييز القيمة بالجنيه من النسبة المئوية. المصدر الحالي يسمح بالنسبة من الأجر الأساسي فقط، ويحسب القيمة المدخلة بقسمتها على 100.
- الاستحقاق السنوي: توضيح أن سبب التسجيل مطلوب من 3 أحرف، وشرح سبب تعطيل التأكيد، وتبسيط مدة الخدمة وعدد أيام السنة. شرط التسجيل وحساباته محفوظان؛ العلامة البصرية لا تفرض تحققًا أصليًا يمنع المعاينة أو حفظ السياسة.
- 28 صفحة إضافية تشارك عميل الخادم وقراءة المستخدم داخل الطلب نفسه مع الإطار؛ لا تخزين بين الطلبات أو الحسابات. لم يُقَس تحسن زمن التنقل بعد.

## ما يفصل التنفيذ عن إعلان الجاهزية
جولة قبول مركزة على نسخة `6861fee02d62bc07cb8329db3a66eeb93f644bfa`: نجح الدخول الفعلي للشركة والموظف، وخروج الهيدر للحسابين إلى صفحة الدخول برسالة تأكيد. صفحة الرواتب رفضت وصول الموظف كما يجب دون محاولة تجاوزها. في عرض390px لم يظهر فيض أفقي عام في الرواتب وإجازاتي؛ شريط تبويبات الرواتب قابل للتمرير. هذا قبول لهذه الحالات المحدودة، لا لكل الصفحات والأدوار.

القبول المالي بقي غير مكتمل: قاعدة QA بلا `statutory_packs` أو `statutory_draft_issuances`، وبلا مسيرات نهائية مؤهلة. المراجعة أظهرت10عوائق، منها قواعد الحساب والبيانات الضريبية/التأمينية والأرصدة الافتتاحية وسياسة الحساب واحتساب الحضور والإجازات؛ لم تظهر إجراءات اعتماد أو حفظ نهائي أو دفع للمسير غير المؤهل. المصدر يحتوي دمجًا ماليًا محدودًا للأجر اليومي والمصادر المستوفية للشروط، ويرفض التأخير والانصراف المبكر والإضافي غير المرفوض؛ لا يكفي ملء بيانات عامة لقبول رواتب شهرية متكاملة. لم تُنشأ قواعد أو إصدارات مصطنعة لاجتياز الجولة.

انتقالان بعد التجميع في نسخة التطوير: الرواتب2.600ثانية (زمن التطبيق2.200)، ومراجعة المسير1.724ثانية (التطبيق1.460). الفتح الأول23ثانية تضمن20.8ثانية تجميع؛ هذه ليست قياسات أداء إنتاج. فحص مشغّل المنصة لم يكتمل، واختبار الجهاز الفعلي ما زال عند المالك.

أُغلقت الجولة: منافذ3716/3717 لا تستمع، واستُعيدت بيانات الدخول الأصلية للحسابات الاصطناعية الثلاثة داخل قاعدة QA مع تحقق المطابقة دون إخراج أسرار، وأُعيد انتهاء اتصال Auth/REST إلى`2026-10-09 20:02:20.39+00`، وأزيلت نسخ الاستعادة الخاصة بالمهمة. البيانات والحاويات محفوظة. لم تتغير ملفات كود المنتج أو قواعد الحساب أو مهاجراته أو صلاحياته؛ لا دمج أو نشر أو Actions من الجولة.

1. أصل خطأ `SQLSTATE 28P01`: انتهت صلاحية اتصال حسابَي Auth وREST المحليين. بعد تفويض المالك يوم10أكتوبر، استُخدم حساب الصيانة المخصص `ux_qa_admin` لتجديد الصلاحية مؤقتًا ساعتين، دون تغيير كلمات المرور أو منح صلاحيات أو إعادة إنشاء البيانات. `postgres` حساب NOLOGIN في هذه القاعدة؛ محاولة استعماله رُفضت وتوقفت، ولم يُغيّر قيده. الدخول والخروج الفعليان نجحا بعدها.
2. جولة محلية بعرض390px شملت مساحة الرواتب والدورة والمدخلات والسلف ومراجعة المسير والتقارير، دليل الموظفين ومعاينة/ملف موظف وتبويباته، قائمة الإجازات ومراجعة طلب، الحضور، وخدمة إجازات الموظف. أُرسل طلب تجريبي واحد ثم سُحب من الواجهة؛ لم يُعتمد أو يُخصم رصيد. أُصلح إرشاد التقرير الفارغ ونهاية النتائج، وغياب قوالب الدوام، ولغة ربط الحساب بالحضور. لا تغيير للمعاملات أو الصلاحيات، ولا اختبارات خلفية ثقيلة.
3. قاعدة الاختبار تحتوي صفر `payroll.final_contexts`. عرض المسير النهائي ومطابقة الدفعات والتصحيح على مسير نهائي والتقارير ذات البيانات لم تُقبل فعليًا بهذه الجولة. شاشة المراجعة تُظهر موانع تأهيل مالية ودمج الحضور والإجازات قائمة بالفعل؛ لم تُخفَ أو تُتجاوز. يلزم سيناريو مسير نهائي مؤهل في الاختبار قبل قبول هذه الحالات؛ لا إثبات لجاهزية مالية أو إنتاج من مراجعة التصميم.
4. المالك يتولى اختبار جهازه الفعلي للموقع والتثبيت والملاحظات البصرية قبل النشر. لا إعلان جاهزية إنتاج أو دمج أو نشر في هذه الدفعة. زمن تجميع نسخة التطوير ليس قياسًا لأداء الإنتاج.

تفاصيل راتب الموظف تُفتح عند الطلب مع بقاء الأجر الأساسي والصافي ظاهرين، وإرشاد واضح لنهاية النتائج في المسير والدفعات. مراجعة Claude Opus 5.5 Medium لهذه الدفعة لم تجد تراجعًا ملموسًا في المصدر؛ قبول هذه الحالات ببيانات نهائية لم يُنفذ. سكربتات الرواتب المالية المقروءة تستخدم محاكاة غير قانونية داخل معاملة تنتهي بـROLLBACK؛ لم تُحوّل إلى بيانات اعتماد دائمة ولم تُشغّل لهذا الغرض.

استُكملت مراجعة العرض المليء بالبيانات للمسير والدفعات والتصحيحات والتقارير في نسخة عرض معزولة: نفس مكونات الصفحات مع استجابات قراءة اصطناعية خارج المستودع، دون قاعدة بيانات أو حفظ أو صرف أو اعتماد. التقرير والتصحيحات أُصلحا بعد المراجعة: اختيارات التقرير في قسم واحد يفتح بلوحة المفاتيح، النماذج GET مستقلة دون تداخل، الموانع قبل الأرقام وبألوان واضحة، وأسماء الموظفين والصافي بسطرين. التقرير عند390px بطاقات بلا فيض أفقي، وعند1366px جدول؛ لا قبول لمعاملات الخادم من هذه المحاكاة. تنسيق المبالغ في التقرير أصبح `12,345.67` مع حفظ القروش كنص، دون تحويل إلى Number. الاختبارات الأربعة القائمة للتنسيق ودقة الأرقام والتصدير نجحت؛ lint وTypeScript نجحا للدفعة. لا توسعة للمنطق المالي أو ترقية لموانع التأهيل إلى أعمال تصميم.

انتهت الإتاحة المحلية المؤقتة: لا مستمع على3710أو3711، وأُعيد تاريخ انتهاء حسابَي اتصال Auth وREST إلى قيمته السابقة. قاعدة الاختبار وحاوياتها وسجلاتها التجريبية محفوظة؛ لا نفق عام جديد أو تغيير لخدمات أخرى.

الفحوص: lint لجميع ملفات TSX المعدلة وبناء مجمع شامل TypeScript ناجحان. مقارنة الصفحات الـ28 أكدت أن الفروق فيها مقصورة على استدعاءات العميل والمستخدم، دون تغيير حراس الصلاحيات أو RPCs. لا تغيير في actions.ts أو Supabase، ولا إعادة اختبارات قاعدة البيانات.

المراجعة الرسمية المصدرية: Claude Opus 5.5 / Medium. ملاحظاته المشروطة عن أساس النسبة ووحدتها وحقول النموذج حُسمت بقراءة قواعد الخيارات والتحقق والحساب ومكوّن Field. مراجعة متابعة محددة صححت نص نهاية النتائج ومعنى صلاحية الربط؛ lint وtypecheck نجحا بعد التصحيح، والبناء السابق محفوظ دون إعادة بنائه لتعديلات الإرشاد وحدها. لا بديل للنموذج ولا تغيير لإعدادات المزود العامة؛ المراجعة المصدرية لا تثبت القبول المرئي لكل الحالات.
