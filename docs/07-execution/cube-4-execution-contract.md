## Ordered vertical slices

Each slice closes UI → supported server command → authoritative transaction → audit/receipt → user outcome. All commands below are **planned operation contracts**, not claims of existing RPCs. Reuse existing shell/primitives and domain service patterns. A slice is complete only with its negative access, failure/recovery, migration and responsive evidence.

1. **Setup and period readiness.** Payroll administrator opens setup, receives a unique-Employer default only when unambiguous, reviews monthly cutoff/effective date/payment rule/timezone, previews explicit local dates and a transition, then saves an effective version. Operator opens the current period and sees owned blockers and one next action. Cancel preview/save returns safely; failed reads retain the form and distinguish unavailable data from empty setup. Calendar supersession preserves generated periods; an affected open run must finish or be explicitly cancelled; pending Attendance and locked history produce warnings. End: valid calendar plus reviewable readiness, no calculation. Gates G1/G2; C01–C07, R01–R02, U01–U04/U07–U08 [S3].
2. **Compensation and approved input readiness.** Configure bounded components/recurring assignments, proration and opening YTD; prepare eligible Employments, approved manual daily units and attributable one-time adjustments. Draft → approve → applied/cancelled adjustment lifecycle is explicit. Introduce G3 before consuming People. Readiness issues show Employee, reason, owner and a permission-compatible source fix, returning to the same Employer/period/filter context. End: reviewed input set or owned blocker; no monetary consumption claim. I01–I10/I03, M04 and A01 [S2 §§3–6,17; S8].
3. **Calculate, review and cancel.** Preparer calculates current inputs; reviewer sees totals, changed Employees, comparable-period variance, anomalies and focused blockers, with human-readable line details on demand. Source/config edits invalidate candidate and review; resolve → recalculate → review. Cover monthly/daily pay, join/end, dated salary changes, proration, transition and YTD. Cancel draft/review retains history without consumption. End: current candidate or explicit cancelled state. G3–G5; I/M cases, L01–L03/L05/L09, U05–U07 [S2 §§4–5,9–11,16–19].
4. **Approve, lock and issue output.** Approval accepts the exact candidate. Lock confirmation shows Employer, actual dates, count, totals and irreversible effect. Revalidate authority and complete current input manifest under compatible locks; append immutable context/results/consumption/audit/receipt atomically. Payslip/export resolves and snapshots legal Employer identity. Dropped-response retry recovers committed result. End: authoritative payable and protected distributable output. G6 prevents exposure before Slices 5–6 closure. L01–L10, O01, A01/A02 [S2 §§9,12–15; S4,S9].
5. **Record and reconcile external payment.** Authorized actor enters paid amount/date/reference against locked payable. Show “تسجيل دفعة تم صرفها خارج النظام”; confirm recorded amount and remaining obligation. Same-attempt replay produces no second payment. Accepted allocation/error/excess policies determine the supported recovery route. End: paid/reconciled or explicit owned remainder. P01–P02/L06–L09, U04 [S2 §§12–13]. No bank transfer execution.
6. **Correct payroll and close final periods.** Unpaid locked error creates linked Amendment Run; original is superseded only when replacement approval+lock succeeds. Any payment, including partial, forbids replacement; use linked next-open-period positive/negative adjustment or approved external settlement, reconciling original paid/remainder/compensation. Old output is visibly superseded for ordinary distribution. Missing target period has an owned recovery action. Ending employment/final-period unsupported termination amounts use a reviewed manual handoff. End: reconciled correction or visible accountable obligation. X01–X05, L10/A02 [S2 §§12–14,18,22].
7. **Advances, installments and settlement.** Finance author drafts principal and deterministic schedule, records external disbursement and activates; approved due installments are consumed once. Cancel only before activation/disbursement responsibility; early/manual settlement and reversal/compensation retain movement history. Balance is ledger-derived; settle only at explained zero. Verified ceilings and accepted insufficient-pay disposition leave unapplied obligations visible. End: attributable outstanding balance or reconciled settlement. F01–F03, I01/L04/L07 [S2 §§6–8].
8. **Reports and complete qualification.** Protected Employer/period reports reconcile authoritative totals, payment, variance, statutory and finance balances; superseded records remain distinguishable. Complete all normal/exception/history/entitlement-loss journeys and exact-candidate fresh/upgrade, concurrency, browser and engineering qualification. End: full technical Cube 4 only when applicable matrix closes; statutory/operational/security/pilot gates remain separately assessed. O02/Q01–Q04/U01–U10 [S1,S2 §§15,23,S11].
