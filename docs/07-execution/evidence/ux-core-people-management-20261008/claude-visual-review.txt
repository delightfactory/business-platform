## Must-fix

1. **Policy catalog content touches the panel edge.** In `policy-after-1366` and `policy-after-390`, the "القوالب المسجلة" heading, the policy name, status and detail lines all sit flush against the panel's right border. Nothing separates one policy as its own card. The create panel directly above it is padded, so the catalog breaks the Concept C card style on the same page.
   - **Fix:** add inner padding and a per-policy card surface to the catalog, using existing classes. No change to fields, wording or actions.
   - I can't tell from screenshots whether this was already there at baseline. It's in the candidate either way.
2. **The date format splits across lines at 390.** In `import-open-390`, the format help wraps `YYYY-MM-DD` as "-YYYY" on one line and "MM-DD" on the next. That makes the exact required format ambiguous, which is what this help text exists to prevent.
   - **Fix:** in `people-management.module.css`, stop the `<bdi>` values inside `.formatHelp` from wrapping (`white-space: nowrap`). No text change.

## Accepted deviations (within the existing contract; owner acceptance not recorded)

- The cards use 8px radius, a border and no avatars. The reference cards are softer and use a larger radius.
- These pages have no global search pill, because native search with a separate button is the existing contract.
- Each page shows one status chip per record.
- Times show seconds (`09:00:00`). That comes from existing data formatting and isn't part of this delta.
