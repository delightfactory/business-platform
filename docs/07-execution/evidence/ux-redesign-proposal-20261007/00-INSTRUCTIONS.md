# تعليمات التنفيذ — اقرأ هذا الملف أولًا

المشروع: delightfactory/business-platform

## محتويات الحزمة
1. `github-issue.md`: نص التذكرة. أول سطر هو العنوان.
2. `ux-redesign-plan.md`: خطة إعادة تصميم الواجهة الكاملة.
3. `ux-concept-c.html`: النموذج الحي المعتمد. يُفتح في أي متصفح.

## المطلوب بالترتيب
1. أنشئ Issue في المستودع بالعنوان والنص من `github-issue.md` كما هو دون تعديل.
2. أنشئ فرعًا باسم `docs/ux-redesign-plan` وأضف:
   - `docs/05-engineering/ux-redesign-plan.md` (الخطة كما هي)
   - `docs/07-execution/evidence/ux-concept-c.html` (النموذج كما هو)
3. افتح Pull Request من هذا الفرع، واربطه بالـ Issue في وصفه.
4. أضف تعليقًا على الـ Issue برابط الـ PR وبمساري الملفين داخل المستودع.

## قيود صارمة
- لا تعدّل أي ملف آخر في المستودع.
- لا تغيّر محتوى الملفات.
- لا تبدأ أي تنفيذ برمجي من الخطة. هذه خطوة توثيق فقط.
- المرجع الذي بُنيت عليه الخطة هو commit `3a310d25c91a84eda52a47cf0491c5a235933a31`.
  - تحقق أن الفرع الأساسي للـ PR يحتوي هذا الـ commit.
  - فرع `main` متوقف عند 1 أكتوبر ولا يحتويه.
  - إن لم تجد فرعًا أساسيًا مناسبًا يحتويه، توقف وأبلغني باسم الفرع الذي يحتويه قبل فتح الـ PR.

## بعد الانتهاء أبلغني بـ
- رابط الـ Issue.
- رابط الـ PR.
- اسم الفرع الأساسي الذي استخدمته.
- قائمة الملفات المتغيرة في الـ PR، ويجب أن تكون ملفين فقط.
