## Must-fix: none confirmed. One item must be verified before acceptance

**Verify before acceptance: the selected employer must stay readable when its name is long.** The header used to show `calendar.employer_name` as plain text. Now the name appears only inside the closed native `<select>` (`page.tsx:84–87`). `.filters select` only has `max-width: 100%` (`payroll.module.css:27`), so at 390px a long employer name gets clipped. In payroll, a cut-off employer identity risks cross-employer confusion. `render-evidence.json` only measured short names, so the 100px width tells us nothing about this case.

Do one of these:
- capture a long-name render at 390px showing the name is still distinguishable; or
- give `.filters select` `width: 100%` below 600px. That is CSS only, with no change to the control.

Don't add the text line back unless the capture fails; it would cost more scan height.
