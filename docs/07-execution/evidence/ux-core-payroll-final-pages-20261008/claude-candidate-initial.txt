## Blocker

**Dead records anchor (`reports/page.tsx:63`).**
- **What happens:** the nav link `{work.rows.length>0&&<a href="#payroll-report-records">}` renders whenever the report has rows. But `id="payroll-report-records"` exists only on the table region. In payslip mode (`report==='payslip' && query.employee`), the rows render as `.payslip` articles with no such ID, so the link goes nowhere.
- **Why the evidence missed it:** `screen-metrics.json` checks link targets only for the `reports-sheet-ready` scene, and the payslip scenes in `print-metrics.json` don't check nav targets.
- **Fix (either):**
  - add `!(report==='payslip'&&query.employee)` to the link's condition; or
  - put the ID on the first `.payslip` article (`index===0`). This is safe for printing because the payslip print rules use classes, not structure.
- Then re-run the payslip screen scene with the target check.
