## Source verdict: **APPROVE as a source-qualified candidate**

**Daily (`page.tsx`)**
- **Unchanged:** guard order, the `open_day`/`day_list` split (28–30), cursor ≤40, and the overtime summary (still failing silently, a known risk). The auth redirect at line 21 has the same bare `next`.
- **Authorized links:** the four links (51–54) keep their exact conditions and hrefs. They moved into one `nav` next to the date form.
- **Failure copy (31):** neutral and true for both RPCs. `retryHref` (17) is the normalized `date` plus `cursor` only when the cursor is valid. Adding it to the no-client status (19) is the same safe GET.
- **Date form (49):** native GET, the label contains the input, and `id`/`name` are unchanged. A new date drops the cursor, as before.
- **Table (58–77):**
  - Native `<table>` with a caption that says "المعروضة في هذه الصفحة", so it claims no whole-day total.
  - `th scope="col"`, plus explicit `table/rowgroup/row/columnheader/rowheader/cell` roles.
  - Mobile labels are `aria-hidden`, and the record link is described by the row's `h2`.
  - Every payload from the 7.4 audit is present: name, code, flexible/fixed schedule in the row's timezone, metrics gate, both exception messages, overtime count, link.
- **Pagination (78–80):** unchanged.

**Review (`review/page.tsx`)**
- Only two additions: the `reviewPage` class and the toolbar wrapper with the label containing the input (37, 43).
- Unchanged:
  - The queue RPC and its params
  - The filters and their existing counts

**CSS:** every token used is defined (`tokens.css:5-40`, `workspace.css:503`). Radius is `.5rem` (8px), and below 900px cards are built from the same markup.

**Introduced must-fix items:** none.

## Scoped visual verdict: **MATCH WITH ACCEPTED DEVIATIONS**
This covers the table/list/card controls and body only, rendered with a synthetic parent, synthetic SDK and synthetic roles.

- **Desktop RTL column order (after-1366):** right to left it's الموظف → الدوام المتوقع → مؤشرات اليوم والمراجعة → الحالة → الإجراء. Employee is first and the action is last, as in the reference. Headers are visible and the caption is above the table.
- **Mobile (after-390, daily-card-390):** each card shows the name, code, labelled "الدوام المتوقع", "مؤشرات اليوم والمراجعة" with both error messages, "الحالة" with the pill, and a "فتح السجل" link with no label. Nothing is cut off, and the cards replace the reference's horizontal-overflow table, which was the defect.
- **Review (review-1366/390):** two card columns on desktop and one on mobile. The filter links show the existing counts, the active filter is marked, and "مراجعة السجل" sits at the bottom of each card.

- No status segmentation (no status filter in the RPC, so it stays OPEN).
- No avatars, branch column or actual-punch column.
- No "استيراد ملف"-only toolbar: all four authorized links are kept.
- A synthetic sidebar stands in for the real parent.
