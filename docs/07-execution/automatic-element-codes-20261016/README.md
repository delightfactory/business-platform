# الأكواد المقترحة تلقائيًا عند الإنشاء

طلب المالك: اقتراح كود تلقائي مع إمكانية تغييره، ومنع التكرار عند الحفظ. هذه إضافة محدودة لسلوك تهيئة النماذج؛ لا تغير صلاحيات أو سجلات قائمة أو قواعد مالية.

## الحصر

| مسار الإنشاء | الحقل | الحالة قبل التعديل | التفرد عند الحفظ |
|---|---|---|---|
| إضافة موظف | code | مولد قابل للتعديل | داخل الشركة، دون اعتبار حالة الأحرف |
| قسم جديد | code | فارغ يدويًا | داخل الشركة، دون اعتبار حالة الأحرف |
| وظيفة جديدة | code | فارغ يدويًا | داخل الشركة، دون اعتبار حالة الأحرف |
| قالب دوام جديد | code | مولد قابل للتعديل | قالب داخل الشركة؛ يطبّع إلى أحرف كبيرة |
| نوع إجازة جديد | code | مولد قابل للتعديل | جهة العمل داخل الشركة |
| تقويم إجازات جديد | code | مولد قابل للتعديل | جهة العمل داخل الشركة |
| بند راتب جديد | key | فارغ يدويًا | جهة العمل داخل الشركة؛ فحص داخل قفل نطاق الإدخال |
| موظف جديد ضمن اقتراح تصحيح توظيف | employee_code | فارغ يدويًا | داخل الشركة عند تطبيق المسار المعتمد |

الأقسام والوظائف تشتركان في نموذج واحد. بنود الرواتب ومقترحات التصحيح لها حقول ديناميكية؛ لذلك لا يكفي البحث عن `name="code"` وحده.

## العقد المحدود

- توليد المقترح في الخادم عند فتح نموذج إنشاء جديد، ثم تمريره للعميل؛ لا توليد أثناء كل render أو عند تغيير الاسم.
- يبقى الحقل قابلًا للتعديل وبنفس قواعد الحفظ. يحتفظ النموذج بالقيمة المعدلة بعد الفشل؛ لا استبدال تلقائي لكود طلب نتيجته مجهولة.
- الرموز الجديدة للأقسام والوظائف والبنود لها بادئة مفهومة ولا تعتمد على عدّ الصفوف أو `MAX+1` أو قائمة نتائج محدودة.
- المقترح ليس حجزًا ولا ضمانًا لعدم التصادم. قيود قاعدة البيانات وقفل نطاق الرواتب هما المرجع النهائي، بما يشمل الطلبات المتزامنة. رفض التكرار لا يعيد الإرسال أو يغير نية المستخدم تلقائيًا.
- لا تتغير أكواد السجلات القائمة أو أكواد بند راتب يجري تصحيح إصداره، ولا يعاد ترقيم أي سجل.
- إضافة واحدة بسيطة في مسار المستخدم: يكتب الاسم وباقي بيانات العمل ويترك الكود المقترح، أو يعدّله إذا كان للشركة نظام ترميز.

## حقول مستبعدة عن قصد

رمز الموظف في جهاز الحضور، رمز المعاملة الضريبية، الفئة التأمينية، مراجع المستندات والموافقات، رموز الموظفين والأقسام والوظائف داخل ملفات الاستيراد: قيم مرجعية موجودة في مصدر خارجي، وليست معرفات لعناصر ينشئها هذا النموذج. توليدها يفسد الربط أو الأثر المالي. كذلك UUID ومفاتيح استرجاع الطلبات ليست أكوادًا يكتبها المستخدم.

## التحقق

مطلوب: فحص النوع والـlint، عينات إنشاء القسم والوظيفة والبند، تعديل المقترح ورفض التكرار مع بقاء القيم، ومراجعة مسار التصحيح دون تنفيذ أثر مالي. نتائج التشغيل تسجل بعد الفحص؛ هذا الحصر ليس شهادة إغلاق كافة رحلات المنصة.
