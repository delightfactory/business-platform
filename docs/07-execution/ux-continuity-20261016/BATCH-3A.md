Entry: sources → add. Outcome: saved source detail with current state; existing branch source leads directly to its edit page. Frequent setup has high privacy/error cost.

Implementation: choose type then branch with inline server-authorized search. One bounded RPC returns active site results and associated existing mobile source including stopped status; first-page absence is never treated as whole-tenant absence. Existing source means direct detail action, while hidden draft remains in memory for another branch. Otherwise name/state/location policy/reason remain required. Permission denial blocks submission. DB uniqueness still protects concurrent creation, with direct existing-source recovery when authoritative lookup succeeds. Unknown write remains unknown and never blindly retried. Browser values retained on all failures. No offline submission or altered business writes. Reasons and audit versions preserved.
