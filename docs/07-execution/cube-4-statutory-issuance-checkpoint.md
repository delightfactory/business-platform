## Implemented boundary

Explicit live Compliance authority is checked before sensitive receipt recovery and again under the existing authority advisory lock and account/grant locks. Draft revision and all comparison evidence are protected by head locking and a review stamp. The original actor/attempt intent replays its immutable outcome; changed intent conflicts. Separate attempts for the same revision return the same issued pack. An issuance and its full reviewed official-comparison history are persisted atomically; an issued revision cannot acquire new comparison evidence, while original comparison receipts still recover. Changing the dossier creates a new revision.

Readiness requires numerical rules, a closed reviewed interval, current matching official-origin cases from saved ETA/NOSI source references and all ten representative scenario labels for each covered year. It structurally checks min/max insured-wage boundaries, mid-year start and prior tax for cumulative/correction cases. Latest official records with the same trimmed name/scenario/year supersede earlier results for eligibility; original records remain in the immutable release evidence. A current mismatch or unrelated source blocks release. Labels and government domain names are not proof of substantive official provenance or representative coverage: release additionally requires the authorized reviewer's explicit provenance/category/period/coverage attestation and reference/reason. That human evidence boundary is not independently satisfied by this delivery.

The immutable pack explicitly records `scope=tax_insurance`, exact draft revision, review stamp, official records, representative IDs and reviewer provenance. `earning_rules` remains empty: there is no inferred earning or labour qualification. Readiness and receipt responses retain `financially_qualified=false`. Existing public calculation, approval/lock and G6 gates are unchanged. Independent conflicts in an overlapping tax treatment or insurance category are rejected, as is duplicate composite scope; identical tax schedules can serve a different insurance category. Replacement/retirement of an already qualified scope is not implemented here and must not be worked around by changing classification identifiers.
