## Namespace and lock corrections

Current request_replay rejects an internal key only inside the existing-event branch; absence of an event is therefore not a complete global reserved-key fence. Do not assume the old internal namespace protects a new prepared attempt, and do not overwrite that correction key behavior.

Prefer explicit private prepared-only identity parameters checked at these locked points. Do not add transaction-local settings, preflight-only protection or undocumented SECURITY DEFINER bypass flags.
